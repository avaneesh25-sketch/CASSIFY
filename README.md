# Cassify — Case Competition Platform (React + Vite + TypeScript)

Think sharper. Play higher. Cassify is an interactive case competition preparation and practice platform for business students, consulting clubs, and academic institutions.

## Features

- **Interactive Case Arena**: Solve structured business cases across Strategy, Growth, and Consumer Retail with instant feedback, rationale explanations, and verified XP awards.
- **Structured Journey**: Progression through Level 01 (The Rookie), Level 02 (The Analyst), Level 03 (The Strategist), and Level 04 (The Contender).
- **Competitor Workspace Dashboard**: Manage active event registrations, deadlines, team rosters, and upload pitch decks.
- **Account & Progress Persistence**: Client-side progress tracking with saved answers and calculated XP.
- **Campus & Institutional Vision**: Access models designed for universities, consulting clubs, and case societies.
- **Privacy & Analytics Choices**: Granular consent settings and privacy documentation.
- **Sandbox Checkout Demonstration**: Test payment preview integration.

## Tech Stack

- **Framework**: React 19, TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS with custom design system preserving original typography and brand palette

## Getting Started

```bash
# Install dependencies
npm install

# Run development server (runs on port 3000)
npm run dev

# Build for production
npm run build
```
